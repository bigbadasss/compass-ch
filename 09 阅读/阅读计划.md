# 阅读计划

每天阅读的每一章或每一节对应一个任务，并用 `⏳` 标记计划阅读日期。每日笔记中的“每日阅读”区域会查询计划日期不晚于今天的项目，因此未读内容会自动顺延。如果正文保存在 Vault 中，请把任务链接到 `09 阅读/章节/` 中的对应笔记。

格式：
```
- [ ] 阅读 [[创世记 1]] ⏳ 2027-01-01
- [ ] 阅读《原子习惯》第 3 章 ⏳ 2027-01-02
```

圣经阅读者可运行 `scripts/generate_reading_plan.py --start YYYY-MM-DD --days 365`，把完整的 1,189 章计划写入此文件；`scripts/split_bible.py` 可生成章节与经文笔记。参见 [[07 工作流 - 每日阅读]]。
