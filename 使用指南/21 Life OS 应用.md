# Life OS 应用

Life OS 是 Compass Vault 上方的原生应用层。它提供统一导航、捕获和数据概览，底层数据仍然是 Markdown 和属性，没有第二套数据库，也不依赖云端数据库。

## 打开方式

- Obsidian 启动后自动打开。
- 按 Ctrl/Cmd+Shift+L。
- 点击指南针图标。
- 在命令面板中运行 **Life OS：打开 Life OS 主页**。

升级后没有出现时，在命令面板中运行一次“重新载入应用且不保存”。

## 模块

| 模块 | 用途 | 数据来源 |
| --- | --- | --- |
| 主页 | 快速定位、记录、计划和 AI 入口 | 仪表盘和工作流链接 |
| 今天 | 每日问题、习惯、日记、收获、感恩和任务 | 今日笔记与 QuickAdd |
| 规划 | 每日、每周、季度、项目和理想一周 | 周期笔记与计划笔记 |
| 专注 | 当前需要注意的承诺 | 任务和项目 |
| 回顾 | 跨日期和季度的记录 | 每日属性与周期回顾 |
| 项目 | 进行中的成果和项目想法 | `04 项目` |
| 人物 | 人物关系和待讨论事项 | `05 人物` 与 `#discuss` |
| 创作 | 写作内容流程 | `06 写作` 看板 |
| 资料库 | 阅读、书籍、来源和链接笔记 | `07 资料库` 与 `09 阅读` |
| AI | 检索、整理、起草和设置 | AI 助手、提示词、MCP |

## 知识图谱

知识图谱把笔记放入五个彩色区域。连接只来自 Obsidian 已解析的真实链接，背景脑形线条只是装饰。可以旋转、缩放、搜索、筛选、选择节点并打开来源笔记。为保证性能，完整视图最多显示 2,000 篇笔记和 10,000 条链接。

## 数据与隐私

- “今天”模块通过本地元数据缓存读取 `dq_*` 和 `habit_*`，不显示或发送日记正文。
- 捕获按钮运行现有 QuickAdd 命令。
- “回顾”模块默认排除示例数据，缺失值保持空白。
- AI 模块只显示集成状态，本身不会测试模型身份验证或发送请求。
- 人工批准是操作规则，但不是所有客户端都能强制执行的技术保证。

## 中文版维护说明

中文版已维护 `.obsidian/plugins/life-os-app/main.js` 的用户界面文字，并同步修改相关路径、设置和自动验证。机器标识、命令 ID、属性键和第三方产品名称保持原样，以免破坏插件功能。以后同步英文上游时，应先查看 `汉化记录/`，再把 Life OS 新增的用户界面文字翻译并重新运行验证。
