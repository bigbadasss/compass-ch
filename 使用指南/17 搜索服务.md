# 搜索服务

Vault 可以使用不同搜索方式，各自适合不同场景。

| 服务 | 用途 | 说明 |
| --- | --- | --- |
| Obsidian 搜索 | 内置全文搜索 | 无需额外配置 |
| Omnisearch | 更强的 Vault 内搜索 | 适合标题和正文查找 |
| Local REST API | 浏览器扩展和外部工具 | 需要本地密钥，只应在回环地址使用 |
| Obsidian MCP | AI 代理的结构化工具 | 可读取、搜索、打开和按规则修改笔记 |

## Vault Lens 连接

1. 确认 Omnisearch 和 Local REST API 已启用。
2. 从 Local REST API 设置中取得本机生成的密钥，不要保存到仓库。
3. 在扩展中选择对应提供方并测试搜索。
4. 用不敏感的测试笔记确认预览、打开和编辑边界。

“已填写密钥”不等于连接成功。只有实际搜索并打开正确笔记，才算完成验证。
