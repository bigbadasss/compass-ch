# Compass 仪表盘

[[Compass 总览|Compass 仪表盘]] 使用 DataviewJS 从普通 Markdown 和属性实时生成内容，不维护第二套数据库。

## 组件

- 快捷链接：今天、本周、本季度和季度回顾。
- 快捷捕获：日记、收获、感恩和任务。
- 人生主题：嵌入 人生主题 的 人生主题 部分。
- 生命之轮：读取最近一次或本季度季度回顾的 `wheel_*`。
- 每日问题：读取 `dq_*`，显示趋势和平均值。
- 习惯：读取 `habit_*`，显示连续天数和完成率。
- 看板：读取带 `kanban-plugin` 属性的笔记。
- 人生倒计时：根据出生日期和预期寿命计算。

## 空状态

刚开始使用时没有数据是正常的。示例笔记让图表在第一次打开时有内容；积累真实数据后，可以删除带 `example` 标签的笔记。

## 故障检查

1. 确认第三方插件已启用。
2. 确认 Dataview JavaScript 查询已开启。
3. 确认 [[Compass 配置|Compass 配置]] 中的路径与实际文件夹一致。
4. 检查脚本错误时运行项目验证命令，或打开 [[初始设置|初始化设置]] 查看状态清单。
