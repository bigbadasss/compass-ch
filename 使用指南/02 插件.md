# 插件说明

## 已安装插件

| 插件 | ID | 用途 |
| --- | --- | --- |
| QuickAdd | `quickadd` | 捕获日记、收获、感恩、任务和创意；创建标准笔记 |
| Periodic Notes | `periodic-notes` | 导航每日、每周和季度笔记 |
| Tasks | `obsidian-tasks-plugin` | 行内任务与任务查询 |
| Dataview | `dataview` | 仪表盘、生命之轮、习惯和每日问题图表 |
| Kanban | `obsidian-kanban` | 项目和写作看板 |
| Templater | `templater-obsidian` | 日期计算、文件夹模板和每日问题弹窗 |
| Agent Client | `agent-client` | 在 Obsidian 内使用本地代理 |
| SEO | `seo` | 发布前检查写作笔记 |
| Omnisearch | `omnisearch` | Vault 内搜索 |
| Local REST API | `obsidian-local-rest-api` | 本地 API、MCP 和 Vault Lens 数据接口 |
| Life OS | `life-os-app` | 原生导航、捕获和工作流界面 |

第三方插件保留各自许可证，详见根目录的 `THIRD_PARTY_NOTICES.md`。

## 首次打开检查

1. 前往“设置 → 第三方插件”，关闭安全模式。必要时运行 **Reload app without saving**。
2. 前往“设置 → 外观 → CSS 代码片段”，确认 `lifeos` 已启用。
3. 在 Templater 中确认“创建新文件时触发”和“文件夹模板”已开启。
4. 确认 Periodic Notes 的每日、每周和季度路径与 [[Compass 配置|Compass 配置]] 一致。
5. 确认 QuickAdd 选项旁的闪电图标已开启，使它们可以作为命令运行。
6. 在 Dataview 中启用 JavaScript 查询。
7. 打开 [[Compass 总览|Compass 仪表盘]]。显示“尚无数据”属于正常空状态。

## 预设快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl/Cmd+Shift+L | 打开 Life OS |
| Ctrl/Cmd+Shift+C | 打开通用捕获 |
| Ctrl/Cmd+Shift+D | 创建或打开今日笔记 |
| Ctrl/Cmd+Alt+W | 创建或打开本周周记 |
| Ctrl/Cmd+Alt+Q | 创建或打开本季度笔记 |
| Ctrl/Cmd+Shift+J | 写日记 |
| Ctrl/Cmd+Shift+W | 记录收获 |
| Ctrl/Cmd+Shift+G | 记录感恩 |
| Ctrl/Cmd+Shift+T | 添加任务 |
| Ctrl/Cmd+Shift+Q | 打开每日问题弹窗 |

## 为什么部分名称保留英文

QuickAdd 会精确查找“日记”“收获”“感恩”“收件箱”等标题。中文版已经同步修改按钮、说明、目标目录和标题；`lifeos-*` 等命令 ID 保持不变，以免快捷键和 Life OS 调用失效。

插件更新仍通过“设置 → 第三方插件 → 检查更新”完成。更新前请备份并在测试 Vault 中验证。
