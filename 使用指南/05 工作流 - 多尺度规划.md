# 工作流：多尺度计划

多尺度计划让每天做的事情与季度回顾中决定的重要方向保持一致。

## 四个层级

| 层级 | 内容 | 位置 |
| --- | --- | --- |
| 人生方向 | 人生主题、核心价值观、角色 | `03 规划/` |
| 季度 | 意图、关注领域、项目 | `01 日志/每季度/` 和 `02 季度回顾/` |
| 每周 | 三项本周意图、理想一周检查、到期任务 | `01 日志/每周/` |
| 每日 | 今日任务、日记、习惯和每日问题 | `01 日志/每日/` |

## 使用节奏

1. 每季度通过个人回顾决定未来 90 天的重点。
2. 每周选择最多三件能推动季度意图的事情。
3. 每天查看本周意图和今天真正需要处理的任务。
4. 周末根据每日记录完成回顾，不凭印象打分。

## 为什么没有年度计划

年度跨度太长，难以预测。季度足够长，可以推进有意义的项目，也足够短，可以根据现实情况重置。

## 创建周期笔记

- 每日笔记：Ctrl/Cmd+Shift+D
- 周记：Ctrl/Cmd+Alt+W
- 季度笔记：Ctrl/Cmd+Alt+Q

这些命令使用固定的中文路径、日期格式和模板。不要单独改名，否则 Periodic Notes、Templater 和仪表盘会失去对应关系。
