# Kanban 看板

看板仍然是普通 Markdown 文件。每个二级标题是一个泳道，每个复选框行是一张卡片。

## 默认看板

- 项目：`04 项目/项目看板.md`
- 新闻通讯：`06 写作/新闻通讯/新闻通讯看板.md`
- 视频：`06 写作/视频脚本/视频看板.md`
- 文章：`06 写作/文章/文章看板.md`
- 课程：`06 写作/课程内容/课程看板.md`

## 完成泳道

`系统/Compass 配置.md` 的 `board_done_lanes` 决定哪些泳道计为完成。默认值是 `已完成,已发布,归档`，与中文版默认看板一致。

## 创建新看板

1. 创建普通笔记。
2. 运行 **Kanban: Create new board**，或加入 `kanban-plugin: board` 属性。
3. 建立从左向右的泳道，并把完成泳道放在最后。
4. 需要时设置新笔记文件夹和笔记模板。

## 安全移动卡片

移动卡片时，先把原卡片行插入目标泳道，再从原泳道删除。不要重写整个看板，也不要重排无关卡片。AI 整理流程见 [[09 看板整理]]。
