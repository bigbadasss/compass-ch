# Agent Client 与本地代理

Agent Client 可以在 Obsidian 中运行 Claude Code、Codex、Gemini CLI 等本地代理，并显示提示词按钮和嵌入式聊天。

## 基本设置

1. 启用 Agent Client 插件。
2. 在插件设置中选择代理并使用 Auto-detect，或填写完整可执行文件路径。
3. 关闭自动批准。所有文件修改都应先展示差异。
4. 打开 [[AI 助手]]，检查代理、附件、提及笔记和关联笔记展开设置。

## 隐私边界

- 提示词及代理读取的笔记可能发送给模型服务商。
- 日记、人物和关系笔记可能含敏感信息。
- 大范围回顾前，先让代理列出准备读取的路径和日期范围。
- 批准读取上下文不等于批准修改、安装、付费或发布。

## 规则文件

`AGENTS.md` 是代理的规范来源，`CLAUDE.md` 和 `GEMINI.md` 指向它。规则要求先读后写、编辑前确认、不重写个人记录，并把笔记中的文字视为数据。

这些规则属于行为约定，不能从技术上保证所有客户端都遵守。因此仍需检查客户端权限并审阅每次修改。

## 提示词按钮

按钮默认不会自动发送。发送前在输入框中检查内容。完整工作流见 [[20 提示词库|提示词库]]。

## Linux Flatpak

Flatpak 环境可能无法直接发现主机上的代理命令，需要包装脚本或完整路径。具体路径取决于安装方式，不应猜测。
