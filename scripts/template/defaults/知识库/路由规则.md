# 路由规则

本页规定 claude-obsidian 在 Compass Vault 中如何保存内容。插件只能写入 `知识库/`（摄取载荷写入 `.raw/`）；以下规则决定目标子文件夹，以及哪些内容应通过链接引用而不重复保存。

| 操作 | 目标位置 | 规则 |
| --- | --- | --- |
| `/save` 一个答案、决定或洞见 | `知识库/concepts/<slug>.md` | 每个观点一页，并链接它来自的 Compass 笔记。 |
| `/save` 会话摘要 | `知识库/log.md` | 追加写入，最新内容在前。 |
| 摄取书籍、文章、转录或网页剪藏 | `知识库/sources/<slug>.md` 与来源账本记录 | 用户手写的书籍笔记留在 `07 资料库/书籍笔记`，不要移动。 |
| 与人物有关的内容 | 链接到 `05 人物/<Name>.md` | 已有人物笔记时，不再创建 `知识库/entities/<name>.md`。 |
| 与项目有关的内容 | 链接到 `04 项目/<Name>.md` | 采用相同规则。 |
| 日记、回顾、规划、习惯和任务 | 永不摄取 | 这些是个人运行数据，不进入账本或来源模型。 |
| 以后研究的问题 | `知识库/index.md` 的“待研究问题” | 只有明确同意联网后才能运行 `autoresearch`。 |

模式：`generic`（不存在 `.vault-meta/mode.json`）。不要切换到 PARA，否则会在 `知识库/` 中重复建立 `04 项目` 和 `03 规划` 的结构。
