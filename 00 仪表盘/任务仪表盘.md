使用 QuickAdd 命令 **添加任务** 把所有任务捕获到 [[任务总表|任务总表]] 中。平时不需要直接阅读这份总表。使用 `#project/<slug>` 或 `#p/<person>` 标签，把任务关联到对应项目或人物。下面的查询会在合适的时间显示合适的任务。

## 已逾期
```tasks
not done
path does not include 知识库/
due before today
sort by due
group by filename
```

## 今天
```tasks
not done
path does not include 知识库/
(due on today) OR (scheduled on today)
path does not include 09 阅读/阅读计划
sort by priority
group by filename
```

## 未来 7 天
```tasks
not done
path does not include 知识库/
due after today
due before in 8 days
sort by due
group by due
```

## 待讨论（按人物）
```tasks
not done
path does not include 知识库/
tags include #discuss
group by tags
sort by created
```

## 没有日期的高优先级任务
```tasks
not done
path does not include 知识库/
no due date
(priority is high) OR (priority is highest)
group by filename
```

## 收件箱（无标签、无日期、等待归类）
```tasks
not done
path does not include 知识库/
path includes 08 任务/Tasks
no due date
tags do not include #project
tags do not include #p/
limit 25
```

## 本周已完成
```tasks
done after 7 days ago
path does not include 知识库/
group by done
```
