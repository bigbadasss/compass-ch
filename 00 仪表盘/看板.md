这里实时读取 Vault 中的所有看板文件。卡片从左向右移动，`已完成`、`已发布` 或 `归档` 泳道会被计为完成。看板本质上仍是 Markdown，因此 QuickAdd 的“想法”命令可以直接把内容追加到 `想法` 泳道。

```agent
type: button
text: "整理看板"
prompt: "使用 vault_read 读取 提示词/09 看板整理.md，并按照其中的 “提示词”部分处理我当前打开的笔记；如果当前笔记不适用，则处理当前周期。"
viewType: right-pane
```

## 添加看板
1. 在任意位置创建笔记，打开命令面板并运行 **Kanban: Create new board**，也可以在属性中加入 `kanban-plugin: board`。
2. 为泳道命名。把完成状态的泳道放在最后，并命名为 `已完成`、`已发布` 或 `归档`。如需修改识别列表，请编辑 [[Compass 配置]] 中的 `board_done_lanes`。
3. 可选：在看板设置中指定“新笔记文件夹”和“笔记模板”，让卡片转换成笔记时使用正确模板。
